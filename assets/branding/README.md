# Google Translate attribution

Google에서 배포한 원본 PNG 배지를 수정 없이 사용한다. Flutter와 Android의 밝은 오버레이 모두 color-regular의 1x/2x/3x(mdpi/xhdpi/xxhdpi) 자산을 사용한다. Android 자산은 대응하는 Flutter 원본과 동일한 PNG다.

원본 ZIP: https://docs.cloud.google.com/static/translate/images/google-translate-attribution.zip

사용 지침: https://cloud.google.com/translate/attribution

이 자산은 Google의 상표 및 브랜드 지침에 따른 출처 표시용이다. 앱 자체 로고가 아니며 Google과의 제휴를 나타내지 않는다.
