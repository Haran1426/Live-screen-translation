# ScreenLingo 0.1.9 · 개발 미리보기

**직접 작성한 연습 문장만 시험하는 개발 버전입니다. 민감한 화면/실제 사용자 데이터에는 사용하지 마세요. ARM64 실기기 로그 보호 검증이 남아 있으며 현재 APK는 기존 debug 키로 서명한 최적화 release 빌드입니다.**

## 변경

- 밝은 화이트·옅은 회색/파랑 UI, 불필요한 부제목·장식 배지·모의 번역 카드 제거.
- 영어·한국어·일본어·중국어 기기 내 OCR/번역, 언어 모델 다운로드 후 오프라인 번역.
- 매 세션 Android 화면 공유 동의, 이동/접기/멈춤/재개/종료 가능한 보안 번역 카드.
- Wi-Fi 전용 모델 준비/연결 상태, 본문 글자 3단계/높이 2단계, 분량 제한과 처리 대기 안내.

## 파일

Android 11(API30) 이상이 필요합니다.

| 파일 | 대상 |
| --- | --- |
| `ScreenLingo-0.1.9-android-arm64-v8a.apk` | ARM64 Android 기기. 실기기 실행 미검증 |
| `ScreenLingo-0.1.9-android-armeabi-v7a.apk` | 지원되는 32비트 ARM Android 기기. 실행 미검증 |
| `ScreenLingo-0.1.9-android-x86_64.apk` | x86_64 Android 에뮬레이터 |
| `SHA256SUMS.txt` | 세 APK의 SHA-256 |

## 검증 범위

- Flutter 테스트34개/정적 분석 통과. Android lint 오류0·기존 경고16, debug/3ABI release 빌드 성공.
- 이 버전의 API30 x86_64에서 실제 최적화 release `reading-settings`/`privacy` 각1개 통과: 새 공유 동의/작성된 연습 번역, 큰 글자·카드/제어·출처/회전·멈춤·재개, 로그 양성 대조·본문 payload 부재, 설정 복원.
- 이전 버전의 native29개 단위/다국어·장문·혼합 QA는 개발 문서에 별도로 기록했습니다. 새 버전의 모든 언어·OS·시스템 글꼴·접근성·속도/정확도를 보증하는 결과가 아닙니다.

앱은 캡처/번역 기록을 저장하지 않으며 모델 다운로드 외 번역 서버 API/유료 서비스를 사용하지 않습니다. 현재 샘플 전용 제한과 [로그 보호의 범위](https://github.com/Haran1426/Live-screen-translation/blob/v0.1.9/docs/SECURITY.md)를 유지합니다. Google Translate 공식 출처 표시는 수정하지 않은 원본 배지를 사용합니다.
