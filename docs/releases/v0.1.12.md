# ScreenLingo 0.1.12 · Android 테스트판

Android 11 이상에서 작성된 앱의 연습 화면으로 시험하는 버전입니다. ARM64 실기기 로그 보호 검증이 남아 있습니다. 실제 사용자 데이터나 민감한 화면에 사용하지 마세요. 설치 파일은 기존 개발 인증서로 서명했습니다.

## 변경

- 화면 번역을 시작하면 설정 없이 원문 위치에 번역이 표시됩니다. 동그란 버튼을 누르면 긴 번역을 읽거나 일시정지·종료할 수 있는 카드가 열립니다.
- 화면 줄바꿈으로 끊어진 문장을 이어 번역하고, 긴 문단을 제한할 때는 문장 또는 단어 경계를 우선합니다.
- 앱의 개인정보 안내에 화면 내용의 기기 내 처리와 Google ML Kit의 진단 정보 전송을 구분해 표시합니다.

## 설치 파일

| APK | 대상 |
| --- | --- |
| `ScreenLingo-0.1.12-android-arm64-v8a.apk` | 대부분의 Android 휴대폰 · ARM64 |
| `ScreenLingo-0.1.12-android-armeabi-v7a.apk` | 32비트 ARM 지원 Android 기기 |
| `ScreenLingo-0.1.12-android-x86_64.apk` | x86_64 Android 에뮬레이터 |

기존 개발용 APK와 서명이 일치하면 업데이트로 설치할 수 있습니다. 파일 검증에는 `SHA256SUMS.txt`를 사용하세요.

## 확인한 범위

Flutter 분석과 테스트 34개가 통과했습니다. v0.1.12 x86_64 APK를 Android 11 에뮬레이터에 설치해 실제 화면 공유, 영어 예문의 한국어 번역, 원문 위치 표시, 카드 전환·멈춤·재개와 로그 보호를 확인했습니다. APK 3종의 서명과 패키지 정렬을 검사했습니다. ARM 기기별 동작과 번역 정확도·성능은 별도 검증 대상입니다.
