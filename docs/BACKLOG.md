# 우선순위 백로그

## P0 · 검증/배포 전 필수

- [ ] **사용자가 요청한 설치용 정식 GitHub 릴리스.** 2026-11-20 후속 요청으로 현재 릴리스 작업이 승인됐다. 사용자는 지금 연결할 휴대폰이 없다고 답했다. ARM64 실기기/남은 P0 QA를 완료할 수 없어 정식 게시를 보류한다. 기존 v0.1.9의 pre-release 표시만 바꾸지 않는다. 서명/품질 통과 조건은 [배포 준비](RELEASE.md)를 따른다. 승인을 다시 요구하는 문제가 아니라 실행 환경의 부족이다.
- [ ] **0.1.1부터 적용한 로그 보호를 ARM64 실기기에서 확인.** 0.1.2도 API 30 및 36 x86_64에서 debug/최적화 release 회귀가 통과했다. ARM64 실기기 전에는 샘플 전용/외부 배포 보류를 유지한다. 구형 Android 8~10은 지원하지 않는다. [설계와 재현](SECURITY.md). 실제 장치가 없으면 연결 확인을 반복하지 말고 다음 독립 작업을 진행한다.
- [ ] API33/34 QA. API30/36의 표시 권한 해제·잠금·작업 제거 release 회귀는 완료했다. 추가 OS 환경은 [QA 환경](QA_ENVIRONMENT.md)의 자원/소유 장치 기준을 유지하고 기존 API36 VM을 종료하지 않는다.
- [ ] 0.1.8의 추가 시스템 글꼴/조합·API36/큰 글꼴·TalkBack·다양한 화면 비율 QA. API30에서 선택24sp/높이420의 실제 크기·회전/제어와 기본 번역 경로가 통과했다. 이전0.1.6 CJK 장문3개/기본4언어 회전/영어 제한/Bitmap12방향 완료와 구분한다. 전체 문장·문단 인식률/의미·부정·시간 관계/자연스러움은 별도다. 같은 입력을 반복하기보다 실제 검증 범위를 넓힌다. [범위](MULTILINGUAL_QA.md).
- [ ] 시스템 공유 중지 UI, 최근 앱 UI의 제거 제스처, 회전 연속 조작 QA. 표시 권한 AppOps 해제·잠금·공개 AppTask API의 작업 제거 후 정리/복원/새 동의 회귀는 API30/36에서 완료했다. 설정 토글/최근 앱 제스처/OEM UI는 구분한다.
- [ ] 실제 저성능/ARM64 장치에서 프레임 30초 정책의 적절성과 SDK 장시간 대기 후 메모리 동작을 확인. 결정적 가짜 시계/스케줄러 회귀와 실제 정상 경로 QA를 구분한다. SDK 작업 강제 취소는 지원하지 않는다.

## P1 · MVP 품질

- [ ] 긴 결과 읽기와 원문 가림 추가 개선. 사용자 글자3단계/높이2단계는0.1.8에서 완료했다. 실제 큰 카드의 CJK/다른 시스템 글꼴·조합/창 크기는 위 QA 항목으로 이어간다.
- [ ] 장문을 순차 번역하는 방식/문장 경계 보존을 검토. 최대 12문단/문단당 600 코드포인트로 일부만 선택했다는 안내는 0.1.5에서 완료했다. OCR 누락/가림/짧은 조각 필터까지 모두 탐지하는 기능은 아니다.
- [ ] 변경 화면/스크롤 안정화 감지로 불필요한 OCR 최소화. 상태표시줄과 자체 UI는 현재 제외한다.
- [ ] 모델 크기/다운로드 취소/삭제 UI 검토. 0.1.7에서 기본 연결/준비 요청 안내와 수동 새로고침은 구현했다. SDK 실제 미설치 모델의 Wi-Fi 대기→전송/완료와 VPN/인증 포털 검증은 별도이며, OS 연결 확인을 진행률로 표시하거나 2분 UI 대기를 SDK 취소로 표현하지 않는다.
- [ ] 모델 선택 상태를 묶어 관리하고 실제 다운로드 없는 언어 모델도 테스트할 수 있게 네이티브 계층 주입 개선.
- [ ] 320dp/큰 글꼴/TalkBack/디스플레이 확대와 시스템 다크 모드에서도 밝은 UI·시스템 바의 가독성 추가 QA. 앱 테마를 임의로 어두운 초록 방향으로 되돌리지 않는다.
- [ ] 캡처→OCR→번역 지연과 메모리/발열/배터리 사용을 실기기에서 측정. 근거 없는 목표 수치 표시는 금지.
- [ ] Kotlin 서비스와 오버레이 코드를 더 작은 캡처/번역 세션 객체로 나누고 instrumentation 자동 검증 추가.

## 출시 준비

확정 앱 이름/applicationId, 릴리스 키/서명, 스토어 계정/등록, 개인정보처리방침 및 SDK 데이터 고지, FGS/표시 권한 정책 자료, 외부 배포. 현재 앱은 개발 APK이며 상용 출시 승인을 의미하지 않는다.

후속 사용자 요청은 검증을 마친 설치용 GitHub 릴리스까지 포함한다. 필요한 배포 준비를 진행하되, 현재 실기기 부재를 숨기거나 미검증 상태로 정식 배포하지 않는다. 스토어 계정/등록·유료 서비스까지 요청한 것으로 확대하지 않는다. 일반 release의 자동 debug 서명은 제거했고 실제 배포 키는 아직 생성하지 않았다.

2026-11-20 사용자가 지정한 GitHub 저장소의 소스 업데이트와0.1.9 개발 미리보기 릴리스 게시를 직접 요청했다. 이 요청은 해당 저장소의 이번 commit/push/샘플 전용 pre-release를 승인한 것이며, 샘플 제한 해제·새 서명 키·스토어/정식 배포나 이후 자동 게시를 승인한 것은 아니다.
