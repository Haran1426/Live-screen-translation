# 제품 기획 · v0.1

## 해결할 문제

외국어 앱, 웹툰/게임, 해외 커뮤니티를 읽을 때 스크린샷을 저장하고 번역 앱으로 옮기는 과정에서 읽던 흐름이 끊긴다. 사용자가 직접 시작한 동안만 현재 화면의 글자를 읽고 같은 화면 위에 번역을 제공한다.

가칭 ScreenLingo. 사용자가 요청한 밝은 분위기에 맞춰 화이트/옅은 회색 배경과 파랑 강조를 사용한다. 짙은 초록과 어두운 대형 카드를 사용하지 않는다. 홈은 언어 선택·준비 상태·시작 제어를 바로 보여준다. 홍보성 문구/장식 배지/불필요한 부제목은 붙이지 않으며 권한·개인정보·상태처럼 필요한 안내만 간결하게 제공한다.

## 초기 사용자와 시나리오

- 해외 게시글: 영어 → 한국어, 스크롤하며 번역 카드를 확인
- 일본어/중국어 앱: 해당 원문 언어를 직접 선택하고 번역
- 학습: 원문을 읽다가 카드를 접고 펼치며 의미 확인

## MVP 범위

Android 11 이상 우선. 기존 Flutter 앱에서 설정/권한/진행상태를 보여주고 Kotlin MediaProjection 서비스에서 캡처한다. 0.1.1은 화면 텍스트가 SDK 진단 로그에 남지 않도록 공개 프로세스 로그 API가 있는 버전으로 범위를 좁혔다. OCR 문자 체계와 번역 언어는 en/ko/ja/zh 4개로 제한한다. 모델 다운로드 후 번역에 API 키나 계정이 필요하지 않다.

읽기 경험의 핵심은 사용자가 멈출 수 있는 번역이다. 다른 앱 위에 떠 있는 접이식 카드, 이동 버튼, 멈춤/재개/종료를 우선한다. 화면 전체를 정확히 덮는 번역은 위치/줄바꿈/터치 전달 검증 후 다음 단계에서 다룬다.

## 사용자 흐름

홈에서 언어 선택 → 표시 권한 → 모델 준비 → 앱의 화면 처리 안내 → Android 알림 권한(선택) → 매 세션 화면 공유 동의 → 다른 앱 전환 → 번역 카드 읽기 → 종료.

필수 권한과 모델이 준비되지 않으면 시작 버튼은 비활성화한다. 동의 취소는 실패 세션을 만들지 않는다. 다운로드 실패 시 이유와 재시도 경로를 표시한다. 번역 도중에는 언어와 주기를 잠가 엔진 설정과 UI의 불일치를 막는다.

언어 준비 전과 요청 중에 기본 네트워크 상태와 Wi-Fi 전용 설정에 따른 안내를 보여준다. 현재 연결만 알 수 있으므로 실제 전송량/진행률/완료 예정 시간을 만들어 표시하지 않는다. 연결 조회 실패는 준비 요청이나 준비된 모델의 오프라인 시작을 막지 않는다. 설정의 연결 새로고침은 모델 다운로드를 다시 요청하지 않는다.

비동기 서비스 오류로 종료되면 홈에 사유를 보여준다. 사용자가 닫은 같은 오류를 새로고침 때 반복하지 않으며, 새로운 실패는 다시 표시한다. 종료 후 자동으로 공유를 재시작하지 않고 준비 상태 확인과 새 동의를 거친다.

연습 화면은 사용자가 선택한 원문 언어의 작성된 문장을 제공한다. 공유 전에는 원문만 읽거나 복사할 수 있고, 공유 동의 후에는 같은 문장의 실제 번역 결과가 오버레이에 표시된다. 한국어·일본어·중국어 원문을 선택했는데 영어 예문이 나오는 혼동을 막는다.

연습 화면 메뉴의 긴 문단·혼합 언어 예문도 현재 원문 언어를 따른다. 혼합 언어 인식의 한계를 안내하며 예문 전환 자체로 공유를 시작하지 않는다. 인식한 문단 중 분량 제한으로 제외·축약한 경우에는 카드와 홈에 일부만 번역했다는 안내와 스크롤해 나눠 읽는 방법을 표시한다. 같은 앞부분을 재사용해도 제한 여부는 현재 화면에 맞춰 바뀌어야 한다.

가로 화면에서는 카드가 오른쪽 일부 폭을 사용하고 제어를 헤더에 모은다. 세로 높이를 무조건 절반으로 줄여 본문이 작아지는 것을 피하고, 상태 안내·Google Translate 출처·멈춤/종료 제어를 유지한다. 실제 회전/큰 글꼴의 읽기 검증은 기기 QA로 확인한다.

설정의 번역 카드 읽기에서 본문을 기본/큰/아주 큰 글자, 카드를 기본/높은 카드로 선택한다. 글자 미리보기는 설정용 작성 문구다. 본문 크기만 바꾸고 제어/출처는 유지하며 시스템 글꼴 설정도 반영한다. 다음 세션부터 적용하고 활성 세션 중에는 잠근다. 높은 카드는 더 많은 원문을 가릴 수 있음을 안내한다. 선택 값만 저장하며 번역문 저장은 하지 않는다.

## 품질 기준

- 빌드뿐 아니라 실제 에뮬레이터에서 OCR/번역을 확인하고 증거와 미검증 항목을 구분한다.
- 캡처 토큰 재사용, 캡처 이미지 저장, 원문 로그, 사용자 모르게 자동 재시작은 하지 않는다.
- 종료/권한 해제/잠금 후 캡처·오버레이·번역 메모리를 정리한다.
- 동시 OCR 작업은 하나로 제한하고 동일 원문의 번역을 세션 내 캐시한다.
- 한 프레임이 30초 안에 끝나지 않으면 세션을 종료하고 새 시작을 안내한다. 멈춤·회전으로 이 기한을 연장하지 않는다. SDK 강제 취소나 처리 속도를 보장하는 수치는 아니다.
- 검증 없이 “즉시”, “정확도 99%”, “배터리 영향 없음”을 주장하지 않는다.
- 홈에 모의 번역 미리보기를 두지 않는다. 글자 크기 미리보기는 작성한 문자 샘플로 구분한다. 실제 번역 시간만 현재 세션에 표시한다.

## 후속 범위

회전/접근성/긴 문단/기기별 OEM 권한 QA, 영역 선택, 원문 위치 대응, 사용자 조절 글자 크기, 언어 모델 관리. 화면과 번역 기록 저장, 클라우드 번역, 로그인, 광고/결제, 스토어 출시는 현재 범위 밖이다.

## 배포 전 결정

확정 제품명/고유 applicationId, 릴리스 서명, 개인정보처리방침 및 SDK 데이터 고지, Google Translate 출처와 보증 문구 검토, FGS/화면 공유 스토어 설명, 실제 기기 성능·전력 측정이 필요하다.
