## 화면 번역

ScreenLingo는 사용자가 번역을 시작하고 Android 화면 공유에 동의한 동안 화면 이미지를 읽습니다. 화면에서 인식한 글자와 번역문을 현재 화면에 표시하기 위해 기기 안에서 처리합니다. 화면 이미지, 인식한 글자 및 번역문은 앱의 번역 세션에서 메모리로 처리합니다. 앱은 번역 기록을 만들거나 이 내용을 파일에 저장하거나 서버에 보내지 않습니다.

번역을 마치면 화면 공유를 종료하고 앱이 보관하던 세션 데이터와 결과를 비웁니다. 사용자가 카드를 열어 번역을 종료하거나 Android의 화면 공유 제어로 공유를 중단할 수 있습니다.

## 설정과 언어 모델

선택한 언어, 화면 확인 간격, 카드 크기와 모델 다운로드 설정을 기기에 저장합니다. 언어 모델은 Google에서 내려받아 기기에 보관합니다. 앱 설정과 모델은 Android의 앱 저장공간 지우기 또는 앱 삭제로 지울 수 있습니다. ScreenLingo에는 사용자 계정 등록 기능이 없습니다.

## Google 서비스

화면 인식과 번역에 Google ML Kit를 사용합니다. Google의 안내에 따르면 ML Kit는 입력 이미지와 인식·번역 결과를 Google 서버에 전송하지 않습니다. 모델 준비와 업데이트, 서비스 진단을 위해 Google에 연결할 수 있습니다.

ML Kit는 앱 버전과 패키지명, 기기와 운영체제 정보, 설치 식별자, 선택한 원문·번역 언어, 처리 시간과 오류 등 사용·진단 정보를 Google로 보낼 수 있습니다. ML Kit의 Firebase 구성요소는 설치 식별자 및 언어·지역·운영체제 등 구성 정보를 처리할 수 있습니다. Google은 해당 정보를 서비스 운영과 진단 및 개선에 사용합니다. Google의 ML Kit 진단 정보는 HTTPS로 전송되며 Google이 관리하는 데이터의 처리·보관에는 Google의 개인정보처리방침이 적용됩니다.

- [Google ML Kit 데이터 공개](https://developers.google.com/ml-kit/android-data-disclosure)
